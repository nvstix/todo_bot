Planvstix — Телеграм бот для списка дел

Описание проекта:
Бот помогает пользователям вести список повседневных задач в Telegram.

Ссылка на бота в Telegram: https://t.me/planvstix_bot

Функционал:
- Добавление задачи (/add)
- Просмотр списка (/list)
- Отметка о выполнении (/done)
- Удаление задачи (/delete)

Технологии:
- Python
- python-telegram-bot
- JSON (файловое хранение)

Запуск бота:
1. Откройте папку с проектом
2. Введите в адресной строке "cmd"
3. Напишите "python bot.py"


Структура проекта:
- bot.py - главный файл для запуска
- handlers.py - обработчики команд
- storage.py - работа с JSON файлом
- tasks.json - файл с данными
- README.md - описание проекта
- DATA_STORAGE.md - документация по хранению

Команды бота:
/start - приветствие
/add текст - добавить задачу
/list - показать список
/done N - отметить задачу N как выполненную
/delete N - удалить задачу N

Хранение данных:
Данные сохраняются в файл tasks.json. Описание структуры - в файле DATA_STORAGE.md
