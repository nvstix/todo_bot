# Документация по хранению данных

## Формат хранения

Данные сохраняются в файл `tasks.json` в формате JSON.

## Структура файла

```json
{
  "123456789": [
    {"title": "Купить хлеб", "done": false},
    {"title": "Сделать зарядку", "done": true}
  ],
  "987654321": [
    {"title": "Позвонить маме", "done": false}
  ]
}
